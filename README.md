# iMasterCloud 智能云管服务平台 · 路演 Demo

**智能是能力、统一是体验、平台来运营。**

React + TypeScript + Tailwind CSS 高保真交互原型，包含客户面4页、伙伴面7页。围绕华东科技大学教学楼A无线体验风险，演示 AI 诊断、工单协同、授权整改、报告交付、经营跟进、案例共创与成长激励的完整闭环。

所有企业、联系人、网络指标、服务、伙伴等级和激励均为虚构演示数据，不代表真实华为产品能力、认证等级或商业政策。无账号、后端、设备连接或外部AI请求。

## 最快开始：离线打开

下载 [单文件演示](artifacts/iMasterCloud-demo.html)，使用 Chrome / Edge / Safari 打开即可。无需安装 Node、启动服务器或联网；CSS、图标及应用逻辑均内嵌。

首页点击 **开始完整演示**，按顶部8个环节逐步讲解；各环节需要实际点击业务动作，不会自动跳过授权或直接写入完成状态。右上角切换客户面 / 伙伴面；刷新保留业务状态；每轮演示前点击重置。

浏览器 `file://` 本地存储策略存在差异，如显示存储不可用提示，可保持当前标签页完成演示，或使用下方 HTTP 运行方式。

## 开发与预览

Node.js 22.12+ 或24，npm。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。默认客户入口 `/#customer`，伙伴入口 `/#partner`。两个角色共用当前浏览器的演示状态。

```bash
npm test             # 关键业务约束与主线测试
npm run build        # TypeScript 检查 + 生产静态资源
npm run preview      # 预览生产构建
npm run package      # 重新生成可双击打开的单文件版
```

## 页面与能力

| 客户面 | 伙伴面 |
| --- | --- |
| 我的智能保障 | 伙伴智能工作台 |
| 我的运行保障 | Aico智能运维中心 |
| 我的服务（工单、报告、套餐） | 统一保障中心 |
| AI智能对话 | 伙伴服务中心 |
| | 智能经营中心 |
| | 伙伴成长中心 |
| | 生态共创中心 |

- AI任务：5步模拟任务画布、设备 / 告警 / 拓扑 / 性能 / 知识关联、结构化结论、继续提问。
- 服务：创建工单、受理、指派、记录进度、授权、整改、验证、交付、客户确认。双方时间轴与数据同步。
- 报告：先讲“发现了什么 / 做了什么 / 改善了什么”；可查看、下载TXT、复制脱敏分享摘要。
- 经营：带设备年限与容量依据的机会，创建线索、跟进记录、客户沟通报告。
- 生态：案例表单、客户授权与脱敏确认、模拟审核、学习清单、模板下载、联合推广。
- 成长：积分账本、等级进度、一次性任务奖励、专项激励申请记录。

## 状态与边界

完整可交互主线仅围绕华东科技大学教学楼A；其他客户是组合总览样例。初始专项工单为0，创建后变为1，客户确认后关闭；其余历史服务数为演示基线。

AI使用规则化模拟，不进行真实模型推理；任务步骤展示数据关联与分析过程。高风险操作须先有受理中的工单和专项诊断，且必须在弹窗中勾选模拟授权。未验证不能交付，未交付不能客户确认。

基础积分8,650，交付+50、客户确认+30、案例审核+100，因此主线完成后为8,830。演示任务还可获得200、600、500分，全部完成后为10,130并升至内部模拟卓越伙伴。重复点击不会重复发奖。积分不等于现金；激励申请仅保留本地待审核记录。

案例附件只记录文件名，文件内容不上传。分享只复制脱敏摘要，不创建公开链接。客户服务与伙伴状态在同一应用内共享，非真实多人协作系统。

本地存储键：`imastercloud-service-demo-v1`。重置只删除本演示的业务状态。首次使用建议在目标路演电脑完成一轮演练。
