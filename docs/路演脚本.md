# iMasterCloud 路演脚本（约8–10分钟）

## 演示准备

1. 优先使用下载好的单文件离线版；建议Chrome / Edge，窗口1366×768或1440×900，浏览器缩放100%。
2. 点右上角重置并确认，再点“开始完整演示”。顶部引导条的下一环节负责导航，不会替代业务操作。
3. 所有业务数据均为虚构。开场明确：展示的是下一代产品概念和流程，不是现行政策或真实网络变更。

## 开场（30秒）

“今天只讲一个客户、一项风险和一次服务。智能是能力，统一是体验，平台来运营。我们希望客户能看见服务价值，也让伙伴能用更高效率交付并持续成长。”

## 1. 客户风险（1分钟）

在“我的智能保障”查看风险提醒，点击“查看风险分析”。说明教学业务影响和分析依据；不直接宣称确定根因。

“客户不需要理解原始告警，只需要知道业务是否受影响、谁在处理、处理到了哪里。”

关闭弹窗，点引导条“下一环节”。此时可不创建工单，后续在伙伴诊断结果直接建单。

## 2. Aico智能诊断（1分钟）

点推荐问题“分析华东科技大学无线体验下降原因”，观察五步任务画布。等待约3秒，看设备、告警、拓扑、性能、历史案例关联及疑似根因。

追问“这个问题以前发生过吗？”。说明历史知识用于辅助判断，不能代替当前证据。

“智能体不仅给出回答，还把结论变成下一步可执行动作。”

## 3. 工单协同（1分钟）

点击“创建服务工单”，确认问题描述与联系人，提交；点击“受理工单”。可用“指派工程师”“更新处理记录”展示服务协同。

切换客户面 → 我的服务，展示同一条工单与时间轴。再切回伙伴面，导航统一保障中心；或用引导条进入下一环节。

## 4. 授权整改（1分钟）

在“统一保障中心”展示云端网管、地端专业能力和O3流程。点击设备查看详情。

依次点击：

1. 模拟授权审批：说明作用范围、维护窗口、短暂重连影响和回退预案；勾选授权确认并提交。
2. 执行模拟整改：留下配置快照与操作记录。
3. 验证优化效果：模拟30分钟观察窗，展示89.2% → 98.6%、86ms → 24ms。

“系统能力可以来自不同后台，但用户的服务流程应该连续。”

## 5. 服务交付（1分钟）

点击“前往服务中心交付报告” → “完成服务并交付报告”。状态变为待客户确认。

点“前往客户面确认”，打开服务报告，按“发现、处理、改善”讲解。点击模拟下载可生成TXT报告，分享复制脱敏摘要。

关闭报告，在客户面点击“确认服务成果”，检查状态为已完成。切回客户首页，风险已缓解，服务次数增加。

## 6. 价值经营（1分钟）

进入伙伴智能经营中心，展示24台设备服役超过5年、容量增长32%、近期3次体验波动。

查看分析依据 → 生成客户沟通报告 → 创建经营线索 → 标记已跟进。

“服务发现的事实形成经营机会，但设备年限并不等于必须采购。先评估现网，再结合客户业务规划沟通。”

## 7. 生态共创（1分钟）

进入生态共创中心 → 分享我的成功案例。表单自动带入本次整改成效，客户名称采用脱敏表述。勾选客户授权，提交后状态为待审核。

点“模拟审核通过”，案例出现在列表，提示获得100成长积分。查看新案例，可加入学习清单、复制模板、申请联合推广。

## 8. 成长激励（1分钟）

进入伙伴成长中心，积分应为8,830。查看明细：交付50、确认30、案例100。

选择演示完成巡检、拓客、交流任务，积分累计至10,130，等级变为“卓越伙伴”。申请专项激励，查看申请记录。

“每次有效使用、服务交付和生态贡献都可被看见。等级和激励是云管内部概念机制，积分不等于现金。”

## 收尾（30秒）

“一个风险从发现到解决、一份服务从交付到复用、一个伙伴从使用平台到获得成长，形成同一条价值链。”

点击结束引导。保留当前状态供交流，下一场再重置。

## 现场恢复

- 刷新页面：业务状态保留，角色回到对应首页；通过左侧导航继续。
- 重复点击建单：打开现有工单，不创建重复专项问题。
- 整改/交付按钮不可点击：检查是否完成诊断、接单、授权或效果验证。
- 无网络：使用单文件版，全流程无需外部API。
- 需要压缩到3分钟：风险 → Aico → 授权整改 → 客户报告 → 已发布案例与积分。
